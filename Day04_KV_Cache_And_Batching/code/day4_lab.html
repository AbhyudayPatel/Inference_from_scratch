nonzero ≈1e-4 is BLAS summation-order noise on |logits|≈130 (relative ~1e-6). The contract is token identity, not bitwise identity — pass threshold 1e-3.

what the cache costs

KV bytes/token = layers × 2 (K+V) × heads × head_dim × dtype = 12×2×12×64×4 B = 73,728 B FP32 (36,864 B FP16, what engines store). This — not weights — is what caps concurrency in Lab 3.

Lab 2 — paged KV: virtual memory for tokens

code/02_paged_kv.py

The memory manager vLLM made famous, simulated exactly: a physical block pool, per-sequence block tables (page tables), a free list, prefix sharing with refcounts, and copy-on-write when a shared partial block is appended to. Change the scenario and watch the pool rewire.

physical block pool — every cell is one token slot

color = owning sequence · number in a block header = physical id · ×N = refcount (shared blocks). Free blocks are faded. Solid fill = used slot, empty = reserved-but-unused (internal fragmentation).

logical → physical block tables

the indirection is the whole idea: a sequence's KV lives in non-contiguous physical blocks, found through its block table — exactly like OS pages.

paged vs reservation-based allocation

the old way (FasterTransformer/Orca) reserves max_len contiguous slots per request up front — the vLLM paper measured 60–80% waste. Paging wastes at most one partial block per sequence.
